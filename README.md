# Medication Manager

Вебдодаток на React для обліку та контролю прийому лікарських засобів.

## Опис
Додаток дозволяє:
- додавати препарати;
- задавати кількість доз;
- відстежувати прогрес прийому;
- змінювати значення;
- видаляти записи.

## Технології
- React
- Vite
- JavaScript
- CSS

## Запуск проєкту

Для запуску застосунку необхідно виконати наступні кроки:

1. Відкрити папку проєкту у середовищі розробки (наприклад, Visual Studio Code).
2. Відкрити термінал у папці проєкту.
3. Встановити необхідні залежності за допомогою команди:

```bash
npm install
```
4. Запустити локальний сервер розробки:
```bash
npm run dev
```
Відкрити браузер та перейти за адресою, яка буде вказана у терміналі (наприклад, http://localhost:5173).

Для коректної роботи необхідно, щоб на комп’ютері був встановлений Node.js.
